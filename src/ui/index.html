icms 같은 프로젝트 최상위 폴더를 선택하세요. 하위 폴더의 소스 내용을 함께 검색합니다.

체크된 폴더 아래의 파일 내용에서 화면·함수·API·매퍼·SQL 참조를 검색합니다. 요청ID의 REQ- 다음부터 .xfdl 앞까지의 경로는 검색을 시작하는 단서로 사용합니다.

AI 계정 연결

사용자 계정에서 발급한 API 키로 연결합니다.

요청 이미지가 있으면 이미지 입력을 지원하는 모델을 선택하세요. API 사용 요금과 권한은 연결한 제공업체 계정에 적용됩니다. 목록에 없는 모델도 직접 입력할 수 있습니다.

자료와 결과 보관

요청내용·이미지·분석 결과·검토 메모는 이 PC에 저장됩니다. 외부 AI 분석 시 선택한 요청의 내용·이미지와 연결된 소스 발췌가 설정된 API로 전송됩니다.

API 키는 Windows 암호화 기능으로 저장합니다. PMS 비밀번호 입력과 로그인은 PMS 창에서 사용자가 직접 진행합니다.
